How to Use This Curriculum

  • Study one module at a time.
  • For each module, complete the drills before moving on.
  • Keep a decision scorecard for every candidate alert.

Scorecard templates:

  • docs/templates/decision-scorecard-template.md
  • docs/templates/decision-scorecard-template.csv

Design Principle

This curriculum is process-first. We avoid fixed magic numbers and focus on:

  • context,
  • confirmation,
  • execution realism,
  • and disciplined risk management.
