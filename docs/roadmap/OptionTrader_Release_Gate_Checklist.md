# OptionTrader Release Gate Checklist

Date: 2026-05-11
Status: Active release-control checklist

## Purpose

Define one mandatory, auditable path for release validation so promotion decisions cannot bypass
`S7-CONTRACT-v1` gate evidence.

## Required Command

Run exactly one of the following before any release decision:

```bash
source .venv/bin/activate
python scripts/validate_release.py --config-path config/config-eod-truth.yaml
```

or

```bash
bash scripts/run_release_gate.sh config/config-eod-truth.yaml
```

## Required Evidence Artifacts

A release decision is not valid unless all files below are generated and attached/referenced:

1. `docs/roadmap/OptionTrader_Sprint_7_Release_Validation_Report.md`
2. `docs/roadmap/OptionTrader_Sprint_7_Release_Validation_Payload.json`
3. `docs/roadmap/OptionTrader_Sprint_7_Baseline_Capture_v1.json`

## Closure Criteria

1. Gate output is present and generated by script (no manual spreadsheet substitution).
2. Recommendation is explicit in report and payload (`promotable` or `not_promotable`).
3. Any failed gate has explicit blocking reasons recorded in payload.
4. Issue/PR closure notes reference artifact paths and command used.

## Policy

- If `overall_pass=false`, release recommendation must remain `not_promotable`.
- No manual override is allowed without a new, versioned contract update in roadmap docs.
- Ticket closure without artifact evidence is invalid and must be reopened.
