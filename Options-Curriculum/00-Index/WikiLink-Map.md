## Notes on Aliases

**IV (context-dependent):**
- Use [[IV-Rank]] when discussing implied volatility ranking within a historical window (0–100% scale)
- Use [[IV-Percentile]] when discussing implied volatility as a percentile of historical IV distribution
- If unsure, link to [[IV-Rank]] and let readers navigate to [[IV-Percentile]] if they need the nuance

**Greeks:**
- [[Greeks-Overview]] is the entry point; it links to [[Delta]], [[Gamma]], [[Theta-Decay]], [[Vega]] for deep dives
- Prefer specific greek links ([[Delta]], [[Gamma]], etc.) when your note is about one greek in particular

**0DTE:**
- Notes about 0DTE strategy specifics use [[0DTE-Overview]] as the umbrella, then drill into [[0DTE-Credit-Spread]], [[0DTE-Iron-Condor]], etc.
- 0DTE IC is a convenience alias for [[0DTE-Iron-Condor]]
