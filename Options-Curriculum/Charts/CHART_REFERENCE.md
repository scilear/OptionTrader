## Final QA Checklist

Run these steps in order after generating or regenerating charts.

1. Run `python3 Charts/validate_vault.py <vault-root>` — fix any broken links reported before proceeding.
2. Run `python3 Charts/pnl_diagrams.py` then verify all PNG files exist in `Charts/outputs/`.
3. Repeat for `iv_charts.py`, `timing_charts.py`, `risk_charts.py`, `earnings_charts.py`.
4. Run `python3 Charts/validate_vault.py <vault-root>` again to verify chart embeds resolve.
5. Open Obsidian and check [[Progress-Dashboard]] — confirm notes show correct status.
6. Update the Status column in this file for each chart generated.
